# 维护与验证

本轮仅整理仓库与交付，不改应用功能、权限、按钮样式、配对或资料库格式。

## 保留原则

- `src/` 原样保留。`work/` 的测试、探查和历史维护脚本，以及固定 HTML、媒体与代码片段夹具保留；历史更新脚本会改源码，不应当作测试运行。
- `work/video-web/sample.webm` 被多套原生/浏览器测试直接读取，必须保留。
- `work/native-video/sdk`、固定 NuGet 包、`work/installer/wix-3.14.1` 和 WiX 压缩包是本地构建依赖，保留在 D 盘并排除提交。构建脚本在缺失时按固定地址重新下载并校验。
- `work/*baseline*`、`work/software-main/final-*`、旧报告、差异、备份样本与无法确认用途的固定测试目录先保留在本地，均不作为可独立修改的产品资料库，不上传。这些内容可能支撑历史对比，不能承诺所有历史脚本仍适配 0.18.8。
- 输出目录仅交付最新推荐免安装 ZIP、对应说明与其引用图片。扩展目录、桌面中间目录及兼容包可以由现有构建流程重新生成；需要运行包校验时先构建。

## 清理及发布记录

维护脚本 `work/repository-maintenance.py` 先生成绝对路径约束下的计划和源码哈希，再执行清理；不遍历目录链接，遇链接或锁定文件保留并报告。详细本地清理记录放 `work/repository-maintenance/`，不提交。

上传前检查实际暂存文件、秘密特征及禁止目录；ZIP/MSI 不进 Git 历史。Release 上传原始 0.18.8 ZIP，并以交付说明中的 SHA-256 验证。真实安装、日常登记和实际影片播放不在本轮验证范围。
