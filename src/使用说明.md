# 摸鱼助手 0.18.8

点选网页文字、图片、视频或区域，用滑杆调整大小；按网站保存。适用于桌面 Chrome / Edge，使用通用识别，没有小红书或小黑盒专用规则。

## 升级

用新版覆盖原扩展文件夹，在 chrome://extensions（Edge 为 edge://extensions）点击“重新加载”，再刷新目标网页。无须卸载，旧版保存项会继续保留。

首次安装：打开扩展管理页的“开发者模式”，选择“加载已解压的扩展程序”，选本说明所在的文件夹，并把“摸鱼助手”固定到工具栏。

## 开始调整

1. 点击扩展图标，只打开面板，不进入捕获。首次使用某网站时允许浏览器网站授权。
2. 点击“选择网页内容”，移动鼠标看红框，点击选中。按 Esc 可退出选取。
3. 拖动滑杆或点击百分比 / 字号快捷数值。支持方向键微调滑杆。
4. 需要调整外层时点击“扩大范围 ↑”，需要内层时点击“缩小范围 ↓”。
5. 名称放在保存上方；可以留空，留空沿用自动名称。最后点击“保存到此网站”。

数值输入框左边有两个动态快捷按钮：例如 73% 显示 70% 和 75%，点一下直接设置。比例按 5% 一档，已经在整档时提供前后一档（例如 75% 提供 70% / 80%）；到 10% / 200% 边界时相应按钮置灰。文字字号按 1px 一档。

调整区可切换“整体缩放 / 文字字号”。整体缩放按百分比缩放整个区域，包括内部图片、文字及布局；文字字号只调整文字大小。若刚选中的是一个文字节点，点击整体缩放会进入包住这段文字的元素层，红框同步扩大，原文字层的暂存不丢失。切换模式后可以直接用滑杆或数值框调整，保存后沿用选中的方式。

## 层级与独立暂存

层级放在整个设置面板左边的独立小窗，与滑动条附近对齐，会跟着面板移动。初次选中只显示第 1 层；每点一次扩大或缩小范围，才增加一个尚未探索的层级。向上依次为第 2、3 层；第 1 层内部依次为 -1、-2 层。已探索层级从外到内排列，点击编号可以直接跳转。重新调整已有保存项时，显示该项已经保存的层级。

每层有独立的滑杆参数和“同类内容”状态。切换层级会保留该层的临时预览；新进入的层默认 100%（文字为原始字号）。层级编号上的绿点表示该层已调整。

例如：图片在第 1 层调到 50%，外部区域第 2 层再调到 60%；切回第 1 层，仍能看到原来的 50%。把第 1 层恢复到 100%，第 2 层仍保持 60%。

缩放到 100% 会释放扩展对该层的尺寸约束，恢复该层原有布局。嵌套层同时缩放时效果会相乘，因此可以按上述方式恢复内层，只保留外层调整。

每个层级右边都有 ↺ 复原按钮。不必切换过去，点一下就恢复该层原始大小；文字层恢复原字号。其他层保持不变，当前选中的层也不会切换。未修改的层复原按钮置灰。例如第 1、2、3 层都调过，只想保留第 2、3 层，直接点第 1 层旁的 ↺，最后统一保存。

最后点一次保存，会把本次涉及的各层最终参数保存成一项。关闭面板或重新选取会撤销尚未保存的本次预览。新一轮选取会从第 1 层开始；已保存项可点击“调整”恢复各层参数。

## 两列编号与兄弟元素

左侧表头“层级”“子元素”分别与下面的数字列居中对齐，不加中间的点；每行有“层级、子元素编号、复原”：例如 `2 1` 表示第 2 层当前的第 1 个候选；点击这一行，再点“下一个”，变成 `2 2`，红框移到该层下一个兄弟元素。右侧的 `2 / 8` 表示当前第 2 个、共 8 个可选节点。上一个 / 下一个到达边界时置灰；后续加载的兄弟节点也会更新候选数量。

每组从初次选中的候选编号 1 开始，其他兄弟按网页节点顺序依次排列；从大区域缩小范围时，即使鼠标落在空白，也能先进入一个子元素，再用同层按钮切换。父区域切换后，继续缩小范围会进入这个新区域内部。切回之前的区域，会恢复其先前选中的子元素与数值。

上一个 / 下一个不会自动取消“同类内容一起调整”。新候选继承当前层的同类状态，已访问候选保留其状态。勾选时，同一个选择器匹配到的元素会一起调整，返回这些分支时显示一致的数值；想分别调整兄弟元素时，主动取消同类勾选即可。

取消同类勾选后，同一层多个兄弟可以分别改动，最后一次保存会保存所有已访问分支。行旁的 ↺ 只复原当前显示的子元素，不影响该层其他兄弟；取消修改会撤销全部未保存分支。刷新或重新编辑后，保存的分支参数及当前编号仍可恢复。每项最多保存 100 个元素。

截图优先复用初次选取的底图与当时记录的候选位置；新分支如果不在原始底图的候选缓存中，会在保存时生成所需预览，切换时不为此反复隐藏面板，也不会冒用另一个分支的图。

## 删除网页内容

选中内容后，点击调整区的红底白字“删除选中内容”，该内容会从网页布局中隐藏；勾选“同类内容一起调整”时会一起隐藏匹配内容。按钮随即变成“恢复选中内容”，点击即可恢复，并保留原来的大小参数。层级旁的 ↺ 会同时恢复原始大小和显示状态。

删除可以和其他层的大小调整一起保存，保存列表对应层显示红色“隐藏”，缩放和字号调整显示绿色并注明数值；同一条记录中的各层分别标识。下次访问自动应用。取消修改会撤销本次删除，关闭保存项的启用开关也能恢复显示。删除前自动保留选区预览，不删除网页原始内容。

## 文字与同类内容

鼠标直接落在文字上时，优先检查文字节点；同一容器里有其他文字或图片时，尽量只调整对应文字。不同文字由 br 分隔或混排在 div 里，也可分别选取。一个文字节点内自然换行的多行文字，仍作为同一段文字调整。

“同类内容一起调整”默认勾选。当前项显示红色实线，其他可见匹配项显示红色虚线；取消勾选只调整当前项。编辑旧保存项时沿用其原有状态。

## 浮窗里的保存记录

点击扩展先显示当前网站的保存项，带名称、截图、启用复选框、调整和删除按钮；不会直接进入捕获，也不会打开管理标签页。

面板采用白色底；保存、新增（选择网页内容）和取消修改统一深绿色底、白字；调整区删除内容使用红底白字，保存列表删除记录保持浅底红字；其余操作按钮保持浅绿底、深绿字。选中状态通过边框和标记区分，网页选区仍显示红框。没有保存项时，开始调整的提示直接放在上方按钮里，记录区域显示静态骨架框；全部网站无记录或搜索无结果时也显示骨架框。页面分组之间只保留一条分隔线。

点击“选择网页内容”新增，或点击已有项的“调整”，进入调整状态，隐藏已有记录列表及顶部“选择网页内容”按钮；不再显示“已保存 N 项”按钮。新增选取时只显示顶部“正在选取 · 点击取消”，不显示下面重复的取消按钮。选中内容后，选区标题在“取消修改并返回”按钮上方；点击该按钮撤销本次预览并返回列表。选区截图出现在名称输入框下面，单击可看大图。列表里的名称修改后按 Tab 或点击别处保存，留空恢复自动名称。

点击“保存到此网站”会保存所有暂存层级，然后回到当前网站列表。点“取消修改并返回”、Esc、关闭或重新选取会撤销尚未保存的预览。重新打开扩展默认回到当前网站列表。

保存列表的数值摘要仅显示实际改动的层，未改动的层不占列表空间；多层都有改动时只显示这些层，完全没有改动时显示“原始大小”。内部仍保留探索过的层及分支供重新编辑，自动名称和截图优先取改动内容。

点击列表下方“全部网站记录”，在同一个浮窗里按网站分组查看所有记录，可展开网站并搜索网站或保存项；点击“← 当前网站”返回。每项可开关、改名、删除，网站的“全部启用”只控制该网站全部记录；部分启用时显示半选。当前网页会即时响应开关和删除，其他网站设置相互独立。

同一具体页面的“调整”直接回到编辑；其他页面或网站显示“到网页调整”，优先激活已打开的原网页，没有时打开保存时的网址。这是打开目标内容网页，不是打开管理页。权限被拒绝时需要先在目标网页点击扩展允许访问。

网站下再按页面类型折叠分类：例如 `/app/bbs/home` 和 `/app/bbs/link/*` 分成不同组，数字 ID、长十六进制 ID 和 UUID 会归为 `*`，同类帖子的记录归在一起；普通查询参数和锚点不另分组，`#/` 路由按其路径分组。当前页面类型默认展开。全部网站记录也按“网站 → 页面类型 → 保存项”展示，搜索支持路径。

列表分类只用于整理，不代表同组页面共用调整。带页面网址的记录只在保存时的具体页面生效：按协议、主机、端口、路径和查询参数匹配，数字 ID 不会合并；`#/`、`#!/` 路由也分别隔离，普通 `#comments` 锚点仍属于同一页面。因此 A 页的缩放、字号和隐藏不会影响 B 页的相同元素，B 页保存相同元素会建立自己的记录。网页不刷新而切换地址时，自动移除上一页效果并应用新页记录；未保存的预览会撤销，避免保存到错误页面。已有带网址记录自动使用此规则，无须重存；缺少网址的旧项继续兼容全站生效，保留在“未分类（旧版记录）”中，在原网页调整并保存后绑定该页。无法识别的动态文字 slug 不会自动合并，不加入网站专属元素规则。

## 区域截图与大图

每次新选取只捕获一次网页底图。预览会向外参考最多两层父容器，扩大截图并保留周围内容，同时在截图内画出红色选中范围，方便辨认。仍只截取当时视口内可见的内容，不滚动截长图。

切换扩大 / 缩小范围时，复用同一张底图裁剪并重画红框，不再为每层隐藏面板重新截图。底图反映初次选取时的页面，不会随之后滑杆缩放、滚动或视频播放更新。浏览器回收底图后已生成的预览仍可保存，重新选择可以更新底图。

重新编辑旧保存项时复用已有预览；如果探索并改动了原来没保存的层级，需要的新截图延后到点击保存时生成，切换范围时不隐藏浮窗。

第一次截图期间会短暂隐藏浮窗，避免将设置界面截进图片；随后恢复。保存时压缩预览跟设置一起保存在本机，不下载图片。分层调整优先保存已调整外层的预览；截图不可用时仍能保存参数。重新编辑已有设置时复用原有截图。

在调整界面或保存项中单击截图即可居中看大图，图片带黑色边框；按 Esc、点击关闭或大图外遮罩返回，也支持截图获得焦点后按 Enter 或空格打开。图片限制在 960×640 内并压缩体积；旧图也能打开，清晰度和红框取决于当时保存的版本，需要重新选取保存才能生成新版预览。

旧版保存项没有预览图，调整并重新保存后可生成。

## 左侧标签

面板左上方外侧有三个竖向标签，依次是“点选缩放”“视频待看”和“设置”；图标悬停可查看名称。当前标签显示浅绿色底色、边框和左侧标记。切换标签时，右侧顶栏的名称、图标和主体一起切换；只有点选缩放显示网站副标题。设置页提供点选缩放和视频待看全部已保存设置的导入、导出。支持上下方向键、Home 和 End 切换标签。

切换到设置会保留已调整但未保存的参数，并隐藏红框和层级栏；返回点选缩放可继续调整。如果正在选取时切到设置，选取会停止，返回后需要主动点击按钮再开始。设置页按 Esc 返回点选缩放；再次点击扩展默认回到当前网站保存项。

## 视频待看与跨应用小窗

左侧第二个播放图标是“视频待看”。视频列表全局保存在本机，与各网站的缩放设置分开；切换网页后仍能看到同一份列表。

1. 点击“收藏当前页视频”，收藏当前 B 站视频，或当前页已识别到的网页内视频及 B 站嵌入播放器。也可以点击“点选网页视频加入”，把鼠标移到实际播放器、封面、标题或包含视频的区域；红框显示识别到的视频数，点击即可加入，不必精确点中链接。区域内多个视频会去重加入，封面和标题指向同一视频时只保留一条；不同分集分别保存。支持通用 `<video>`、其 `<source>` 来源、开放 Shadow DOM 内的视频和 B 站嵌入播放器，不加入网站专用选择器。选取时拦截原网页点击，按 Esc 或再次点选取按钮取消；未识别到视频时保留选取并提示。
2. blob / srcObject 等依附原网页的临时视频流，以及没有可保存来源的视频，不再加入列表；点选与“收藏当前页视频”都会自动跳过。红框显示的数量只包含可加入项；区域里同时有临时流和 B 站链接时只加入链接。仅含临时流时提示跳过并继续选取。可粘贴 B 站 BV / av 完整链接，或 MP4 / WebM 等浏览器可播放的视频直链。普通帖子、文章网址本身不是视频源，需打开页面后点选其中的实际视频。B 站链接去掉跟踪参数后去重，`p=2` 等分集单独保存。列表最多 200 条，旧 B 站收藏继续兼容。`b23.tv` 短链接须先在浏览器打开并复制完整链接。
3. 推荐使用“摸鱼助手-免安装版-0.17.4.zip”，完整解压后运行 EXE。点“安装浏览器插件”并加载随附目录；在 EXE 点“配对浏览器插件”进入配对状态，再到浏览器配对页点“配对并授权”。连接和同步成功后两边亮绿灯。已有扩展原位覆盖、重新加载，不先卸载。
4. 双击“摸鱼助手.exe”打开软件，浏览器未连接时只开放设置，连接同步后显示备份；已配对浏览器以后自动连接。扩展图标唤出同一个软件窗口。点击视频“播放”才打开视频小窗，不打开播放器网页或承载标签页。
5. 小窗默认约 480×300 个逻辑像素，按系统显示缩放换算，左右两侧都有箭头，没有浏览器画中画的顶部黑条。悬停或点击箭头展开对应侧的独立控制区，空间不足时换侧，离开后收起；展开不改变视频尺寸，待看列表默认展开。顶部“移动”可按住拖动或用方向键移动窗口，下次播放恢复上次位置，“下一条”可直接换片，“关闭”退出视频窗口（主面板保留）；边缘可调整大小。悬停“安静观看”隐藏扩展按钮和视频区域内的鼠标，移动鼠标或按 Escape 恢复，视频继续播放。扩展面板再次点播放会复用现有窗口。列表统一读写软件资料库，扩展只保留确认后的缓存。
6. 鼠标第一次进入小窗后启用移出隐藏：离开视频和展开控制区即触发隐藏及暂停，取消原来的额外等待和外侧大范围容差；两窗之间的窄缝可通过。拖动或调整大小时不隐藏，松开后按鼠标位置判断。回到原视频窗口区域后显示并恢复本次自动暂停的视频，不覆盖手动暂停。隐藏时不阻挡下层应用，但鼠标进入该区域操作 Excel 也会触发恢复。“移出隐藏”和“置顶”都可取消。

桌面小窗与“视频待看”同步用标题旁的红点标识未看，看过后红点消失。实际播放进度前进后自动标为已看（表示开始观看，不代表看完），也可手动切换；失败不自动标记。两处都有“清除已看视频”，一键移除已看条目，未看保留，当前视频可继续播放。标记随备份导出导入；旧记录默认未看。本地体验页可检测普通视频的实际播放，浏览器兼容小窗中的跨域 B 站播放器无法读取进度时，可手动标记。

“点选网页视频加入”改为深绿底白字，位于“收藏当前页视频”上方。B 站仍使用官方公开嵌入播放器，不再强制关闭弹幕；普通观看时把鼠标移到视频底部可操作原版进度、音量及弹幕控件，安静观看需先移动鼠标或按 Escape 退出。窗口手动缩得太小时，B 站会自行精简界面，放大窗口可恢复；功能范围由 B 站决定。

从浏览器扩展管理页删除本扩展，会清除扩展缓存及配对信息；软件资料库、桌面 MSI、独立 WebView2 登录/缓存与已导出文件保留。安装目录中有“卸载点选缩放视频助手”快捷方式及“这个文件夹是什么.md”。彻底移除时，先卸载助手（清理助手自己的登录、缓存和位置），检查删除残留文件夹，再删除扩展；升级保留助手数据。浏览器本身的网站登录不属于本扩展，不会被清理。
7. 切换、刷新、跳转或关闭原网页不会销毁桌面视频窗口；来源过期或限制外部播放时仍可能失败。点击小窗“关闭”或 Alt+F4 后，停止播放、鼠标检测，播放器与通信进程退出；下次点播放重新启动。
8. 旧临时收藏保留，可手动移除。它们仍依附原网页，沿用原浏览器画中画路径，需要从原网页点击播放；刷新、跳转、关闭原页会结束旧画中画，不支持桌面鼠标隐藏。此兼容路径继续设置隐藏“返回原标签页”按钮，浏览器其余顶栏保留。旧 blob 地址不能跨网页或离线播放。

B 站使用公开嵌入播放器，不要求先登录。桌面助手已在当前电脑现有 WebView2 运行时里验证未登录视频 640×360 解码、进度前进、移出暂停和移回续播；画质、试看、地区和验证要求由 B 站决定，不保证所有视频都能完整播放。普通视频直链也可能受登录、请求头或有效期限制。不会绕过网站验证，不以 iframe load 作为播放成功。

助手安装版只为当前用户部署，安装与登记不请求管理员权限、不修改项目隔离标签。WebView2 资料与缓存写安装目录 `data/webview/`，错误写 `data/last-error.txt`，不读取现有浏览器资料。可从安装目录的卸载入口或 Windows“设置 → 应用”卸载，清理助手自己的登录和缓存，扩展数据保留；升级不清理助手数据。实际安装、自动连接和 Windows 卸载仍待用户执行验证；专用登记下的播放验证不能替代安装验证。扩展只导出自带 MSI，不直接运行未登记的本地安装包，也不增加下载管理权限。详细步骤见配套助手使用说明。

加入时尽量保留标题和封面；粘贴 B 站链接时先以 BV / av 编号显示。此版本不下载视频、不解析高清地址，不提供离线播放或自动连播。收藏信息在本机；播放按原视频来源访问其媒体服务。视频源的有效期、登录、地区、画质和可用性由原网站决定。

离线体验页支持列表界面和本地收藏，播放需要联网；体验页与真实扩展的列表分别存储。体验页继续使用浏览器画中画，不连接桌面助手，也不支持整个窗口鼠标隐藏。扩展目标环境为桌面 Chrome / Edge 120 及以上；配套助手面向 Windows 10 / 11 x64，需要已有 WebView2 Runtime。未连接助手时，原面板提示前往设置连接，不要求输入扩展 ID，不另开网页替代。

## 面板位置

拖动面板顶栏即可移动；顶栏旁的按钮可切到左右侧。位置会记住，调整窗口大小时会限制在视口内。标题栏获得焦点后，方向键可移动，Shift 加方向键可加快。

在真实扩展中，Ctrl＋滚轮或浏览器缩放菜单仍然缩放网页；设置面板、侧边标签和左边层级小窗保持原来的屏幕大小。小窗口中会收窄面板以容纳层级栏。全部网站记录和截图预览也在同一个浮窗中显示。离线体验页没有扩展的浏览器缩放 API，不提供补偿。

## 滚动修复

复用已有元素的尺寸测量结果；仅在目标新增、实际尺寸相关属性变化或窗口大小改变时重新测量。测量期间暂停滚动锚定，保持当前滚动位置，减少缩放后动态加载引起的回跳。

## 权限与数据

只向你主动使用的网站请求访问权限，权限范围按当前网页协议申请。拒绝长期权限时，当前标签页仍可临时使用；要刷新后自动应用，需要允许网站权限。

迁移后，设置、名称、截图、完整待看和已看标记以软件安装目录“资料库”为准；扩展保留已确认缓存，软件关闭时仍自动应用启用规则。保存项按具体 pageURL 匹配，端口、路径、查询参数及路由隔离，普通锚点忽略；缺少 pageURL 的旧项兼容全站。不上传网页内容，没有服务器、账号、遥测或订阅。删除扩展只清其缓存与配对信息，软件资料库保留。

## 导入与导出设置

左侧标签从上到下为“点选缩放、视频待看、设置”；设置页提供全局设置备份入口。

打开左侧“设置”标签页，点击“导出设置”下载 JSON 备份。备份包含所有网站已保存的缩放、字号、隐藏规则、层级与分支、名称、启用状态、截图、全局视频待看列表及面板位置；未保存的调整不包含在内。

点击“导入设置”选择之前导出的 JSON 文件，自动检查并合并，无需额外确认。同一网站中 ID 相同的保存项以备份为准，其他保存项和网站保留；视频按链接与分集等身份去重合并，已有同一视频采用备份信息。备份中的面板位置会恢复，并限制在当前窗口内。可以把备份带到其他浏览器或电脑，重复导入不会重复增加同一条记录。

文件最多 16 MB，每个网站合并后最多 100 个保存项，每项最多 100 个元素，视频合并后最多 200 条。格式错误、无效条目、超出容量或浏览器存储空间不足时会提示失败；先完整检查再写入，不会只导入半份有效内容。数据仍只写入本机，不上传备份文件。

备份不包含视频文件、浏览器登录状态或网站访问授权。导入新浏览器后，仍需在相应网站主动打开扩展并授权，才能自动应用设置。临时视频流仍依附原网页，备份里的旧 blob 地址不能离线播放；网页定位或网站本身发生变化时可能需要重新点选。体验页与真实扩展各自存储，但可交换此备份格式。

## 体验页与边界

双击 demo.html 可离线体验调整、层级与开关；演示页使用自己的本地存储。自动截图需要在普通网页通过真实扩展使用，离线演示保存项显示“无预览”。

通用识别支持开放的 Shadow DOM：可进入多层网页组件，点选内部文字或媒体，按组件路径保存，并在刷新或后续加载同类内容时重新应用。层级扩大 / 缩小可跨越组件边界，同类内容也会显示红框。没有加入 B 站等网站专属选择器。

通用识别不保证所有复杂网页都能一次选对，必要时通过层级扩大或缩小范围。暂不支持跨域 iframe 内部、封闭的 Shadow DOM、浏览器设置页、扩展商店、PDF 内页及全屏视频覆盖层。不能把图片里画出来的文字当作网页文字选取。

网站改版或随机生成样式名可能导致定位失效，需要重新选取。文字细选会插入可撤销的轻量文字包裹节点；网页框架若持续替换内容，可能需要重新选取。缩略图只截取当时可见的区域，不滚动截长图，不下载原始媒体。

首次使用时可先暂停 Stylebot 对同一区域的修改，避免设置叠加。

左侧三个标签与主面板连接为一体，顶部对齐，上下无空隙；选中项右侧与内容区接通，并保留绿色侧边标记。拖动面板、左右停靠及浏览器缩放时保持连接；图标、切换顺序和键盘操作沿用原有方式。

## 软件主界面（0.17.1）

安装本版软件后，可手动打开包含点选缩放、视频待看和设置的主界面。扩展仅保留准备页，承担首次配对、安装升级、网站授权和故障入口；已连接时图标直接唤出软件。首次允许普通网站后自动跟随当前网页，内部页面不能选取，浏览器未连接时只开放设置；连接成功后解锁待看和缩放标签。

网页仍负责实际选区、DOM 修改及临时草稿，桌面通过 UI 快照与操作回传连接，各标签页、文档和网址隔离。主面板无系统标题栏，圆角、连排标签与独立层级块按真实窗口区域裁剪，空隙可点击下层。可拖动、调整大小、置顶，位置和大小自动记住。关闭软件不自动重开；关闭浏览器不关闭软件；无开机启动。浏览器运行时有轻量通信进程用于自动连接和缓存同步。

首次迁移先保留 migration-*.json 恢复备份再提交，不先清空扩展数据，失败可重试。迁移成功后不再反向导入旧缓存或另建可独立修改的收藏库，旧 schemaVersion 1 备份继续兼容。资料库/library.previous.json 是上一次提交；迁移快照可按旧备份导入。卸载软件清理自己的 data 缓存、登录、位置和连接，保留“资料库”及“导出文件”。详细恢复和运行流程见助手文件夹中的“使用说明.md”。

首次打开时的“所有网站”可选授权同时用于自动跟随和选区截图；不修改浏览器“允许访问文件网址”开关，仍只操作普通 HTTP/HTTPS 网页。若不授予，首次未授权网站和截图可能需要回到网页点击扩展图标。
