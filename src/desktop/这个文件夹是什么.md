# 摸鱼助手 0.18.8

打开旁边“摸鱼助手”文件夹，双击“摸鱼助手.exe”。请保留整个文件夹，不要单独移动 EXE。

## 第一次使用

1. 第一张卡片直接选择谷歌浏览器或 Edge。软件会复制 chrome://extensions/ 或 edge://extensions/，并请求打开浏览器和插件目录。没有进入管理页时，在浏览器地址栏粘贴并回车，开启开发者模式，加载“浏览器插件/摸鱼助手”。
2. 第二张卡片自动进入配对等待，选择浏览器暂时禁用。装好插件后，在插件网页点“配对并授权”，按浏览器提示确认；实际通信和资料同步后亮绿灯，点“确认，关闭当前网页”只关闭这张配对页。配对中再次点软件按钮可取消并回到第一步，不断开已有浏览器。成功后留在设置页，可继续选择其他浏览器。

播放器顶部依次为“安静观看、移动、下一条、关闭视频”，侧边栏保留列表与观看设置。开始播放后主面板隐藏，关闭播放器后恢复同一主面板；鼠标移出自动隐藏视频不会打开主面板。软件打开期间会后台预热无视频的播放器界面，关闭软件后释放闲置预热进程，不设开机启动。真正退出后再次运行仍需初始化。

主列表和侧边栏都可选择“标题：展开 / 收起”，收起时只显示一行，超出显示省略号，设置会同步并记住。侧边栏提前准备，内容就绪再显示，列表保持展开，只有错误需要时才显示提示。

虎牙直播间打开后，可点“收藏当前页视频／直播”，保存真实房间编号，并在现有桌面播放器中观看，支持移出隐藏暂停和移回恢复。别名网址通过网页的标准 canonical 信息识别，仍由虎牙决定登录、画质和观看限制；本版不下载视频或保存临时流地址。斗鱼尚未验证成功，暂不列为支持。

未连接时只开放设置，导入导出在连接并同步后显示。已有浏览器保存缓存仍可自动应用网页规则。软件默认置顶，可点顶栏图钉取消；拖动时外形和标签方向不变，松开后才把主面板移回屏幕边界；侧栏放不下时再换到右侧。置顶开启时图钉为深绿底。

## 文件夹里的内容

- 浏览器插件：安装到浏览器的扩展文件。
- 资料库：全部规则、截图、待看、已看标记和迁移恢复快照。
- data：软件自己的网页登录、缓存、位置和连接状态。
- 导出文件：自己导出的 JSON 备份。

移动前关闭浏览器、主面板和视频，移动整个软件文件夹及资料库。新位置运行后重新加载插件并配对。

更新时关闭所有窗口，覆盖程序、依赖、ui 和插件，保留“资料库、data、导出文件”。已有插件在原目录更新并重新加载，不先卸载或清空数据。从旧 MSI 版迁入时先复制完整“资料库”，保留原件。

## 不再使用

先备份需要的数据，在软件点“清除注册表记录”并确认成功，再移除所有浏览器里的本扩展，关闭浏览器和全部软件窗口，删除整个软件文件夹。删除会同时删除里面的资料库和缓存。清理只处理仍指向本目录的连接登记，不删除其他目录或其他软件的记录。

其他位置的旧副本、ZIP、另存备份和快捷方式需要自行处理；旧 MSI 版需单独从 Windows 设置卸载。Windows 和浏览器自己的历史、运行记录不保证自动清理。本软件不设置开机启动或常驻服务，不自动安装依赖，不修改系统安全策略或文件隔离标签。


## 本版操作

- “点选网页视频加入”可连续点选多个封面或标题；加入后继续选，Esc 或原按钮退出。虎牙分区页可点选直播间卡片；别名地址须解析确认房间号，失败请打开房间页再收藏。
- “收藏当前页视频／直播”适用于 B站视频／番剧影视页、虎牙直播间页。链接加入卡片默认收起，支持 B站 BV/av 普通视频、ep 剧集和 ss 季链接、虎牙房间和 MP4/WebM 直链；B站直播尚不支持。季链接依据公开网页的标准 canonical 信息解析成具体剧集并去重；仍用官方嵌入播放器，登录、会员、试看与地区限制由B站决定，不保证每部影片都能在小窗播放。番剧影视可能返回一段错误提示视频，不能将其解码或进度当作正片播放成功；本版番剧影视仅手动标记已看，不因媒体进度自动标记。本轮测试影片“驯龙高手 重回家园”在官方小窗返回错误提示，需回原网页观看。
- 待看列表和播放器侧栏可用“全部 / B站 / 虎牙 / 其他”筛选，仍共用同一份资料库。
- 扩展启用且网站已授权时，普通网页图片悬停可放大预览，无需打开软件或面板，设置中的“鼠标悬停预览图片”默认勾选，可关闭。实际视频、可识别的视频链接封面、标准视频元数据及同一区域内的播放器封面不弹图片气泡，也不创建视频预览，不改变原网页视频播放状态。完全没有链接或媒体线索的静态封面无法保证识别；移开或 Esc 关闭。
- 设置步骤连接成功后自动收起；展开仍可配对其他浏览器。设置区块间距已统一，小鱼图标保持向左并居中。

图片气泡上滚动滚轮可放大、缩小预览框，图片保持比例，不带动下层网页滚动。下一张与刷新后沿用同一尺寸，小窗口自动限制在视口内；写入失败会提示尺寸暂未保存。

气泡出现后位置固定，鼠标可从原图片经过间隙移入气泡，再滚动调整尺寸。连续滚轮不再因气泡换侧而滚到下层网页；缩小时也保持指针在圆角内的可操作位置。离开图片、气泡及连接通道后关闭。
