## 首次运行、更新与旧数据

1. 将 ZIP 完整解压到自己选定的可写文件夹，推荐 D 盘或其他非 C 盘，双击“摸鱼助手.exe”。不需要 MSI 安装或管理员权限，也不设置开机启动。不要只解压或移动 EXE。
2. 软件默认打开设置，未连接时禁用点选缩放与视频待看，连接并同步后恢复，并尝试登记当前用户的浏览器连接入口。设置页显示准备结果；系统阻止时如实提示，备份导入导出在连接并同步后显示，不提权、改安全策略或解除隔离标记。
3. 第一步直接选择“谷歌浏览器 / Edge”，自动复制管理页地址、请求打开浏览器并选中插件文件夹，进入第二步配对等待。Chrome 可能过滤外部传入的内部地址；未进入管理页时在地址栏粘贴并回车。开启开发者模式，加载“浏览器插件/摸鱼助手”，拖入无效时用“加载已解压的扩展程序”。
4. 第二步显示“配对中 · 点击取消”（10 分钟），浏览器选择暂时禁用；再点一次取消并回到第一步，已有连接保留。插件刚安装自动打开配对网页，红灯点击图标也能打开。在网页点“配对并授权”，按浏览器提示确认。通信、资料同步与主面板确认完成后亮绿灯，点“确认，关闭当前网页”仅关闭配对页；软件仍在设置页，并恢复浏览器选择。错误显示在第二步下方。
5. 更新免安装版：先关闭浏览器和全部软件窗口，再覆盖本文件夹中的程序、ui 和插件文件。保留自己的资料库、data 和导出文件，不用空文件夹替换它们。浏览器在原插件目录重新加载，保留 ID 和数据。
6. 从旧 MSI 版改用免安装版：先关闭浏览器、主面板和视频，将旧软件目录里的整个“资料库”复制到免安装文件夹，保留原件作为恢复副本，再运行新版。不要只复制 EXE，或只把浏览器缓存当完整资料库。旧扩展保留 ID，可用新版插件文件覆盖原扩展目录、重新加载并配对；若插件跟随软件移动则加载新位置。没有“资料库”的旧扩展在首次配对时迁移，不先清空扩展存储。

需要已有 .NET Framework 4.6.2+ 和 WebView2 Runtime，不自动安装依赖。本包未签名；真实普通用户首次登记、外部程序确认与不同系统环境仍须实机验证，专用测试登记不能替代它们。浏览器本地文件网址访问不启用，原可选网站权限不变。

## 日常运行

双击软件文件夹中的“摸鱼助手.exe”打开；需要时可自行创建快捷方式。每次未连接时仅设置可用，点选缩放与视频待看两个标签禁用；备份导入导出在连接并同步后显示，已有独立视频可继续播放。顶栏标题旁的灯表示连接状态；配对按钮下方分别显示已配对浏览器图标与状态，可重复点击同一个配对按钮添加浏览器。

已配对的 Chrome / Edge 打开后自动建立连接，无须每天点连接或启动。扩展绿灯时点击图标打开/唤出同一个软件窗口，红灯时只打开配对网页；重复点击不新增同类窗口或配对页。扩展准备页只负责安装升级、配对、网站授权和故障说明。

关闭软件后不会自动重开，也没有开机启动。浏览器运行期间会有轻量的 Native Messaging 通信进程，用于连接与规则缓存同步；它不会自动打开界面。关闭浏览器后通信退出，软件返回设置并禁用另外两个标签，已有独立视频可继续播放。软件主面板与视频分别关闭。

**软件没打开，已保存并启用的网页修改仍会自动应用。** 扩展保留软件已确认的规则缓存，由原内容脚本执行；首次安装的新浏览器需先完成迁移同步与网站授权。软件、连接或资料库出错时不会写出第二套收藏库，保存失败会提示，草稿保留。

## 网页调整与外观

在“点选缩放”点击选择，回到现有浏览器点中网页内容，再调整整体缩放、文字字号、隐藏状态或层级分支并保存。元素识别通用，不添加网站专用规则。带 pageURL 的保存项仅匹配相应具体页面；旧的全站项继续兼容。

网页 DOM、选区和未保存草稿仍由扩展内容脚本管理；桌面展示可信 UI 快照并回传操作。草稿按标签页、文档和网址隔离，刷新或导航会撤销旧文档的未保存修改，不能用旧快照操作新页面。

主面板为无边框原生窗口，保留圆角、相连的三个侧边标签和独立层级块。Win32 窗口区域按真实控件轮廓裁剪，空白与圆角外侧不占点击区域。标题可拖动或用方向键移动，默认置顶，图钉可取消；标签在松开拖动后按边界决定是否翻到右边，位置及大小记忆保留；主面板边缘可调整大小。按钮从 panel.js 的唯一 BUTTON_CSS 构建。

## 数据与恢复

资料库/library.json 是唯一可修改的保存库，包含全部网站规则、截图、隐藏/分支/名称/启用状态、视频列表和已看标记。扩展 chrome.storage.local 在迁移后只保留已确认缓存及本机配对信息，不以旧缓存反向覆盖软件。

首次按每个浏览器扩展实例迁移：先完整验证，再写 migration-*.json 恢复快照，最后原子提交并登记迁移完成；不先清空扩展数据。相同规则 ID 内容冲突会保留两项，视频去重并保留已看状态。容量超限或失败不截断记录，可修复后重试；成功后重连不会重复导入旧数据。

migration-*.json 兼容旧 JSON 备份格式，同时包含迁移前原始数据。library.previous.json 保留上一份校验完整的库。库损坏时报告错误并保留文件，不静默创建空库；关闭软件后可保留损坏文件副本，将完整的 previous 文件恢复为 library.json，或在可运行的软件中导入迁移 JSON。不要编辑校验封装中的 payload。

设置继续兼容原 schemaVersion 1 备份：先全量校验，再按原规则合并，同 ID 备份记录优先、其他记录保留，视频去重。最多16 MB、每站100项、每项100层、视频200条；并发修改以锁、操作 ID 和修订号避免静默覆盖。跨机备份不含连接登记、网站授权、登录及缓存。

## 视频

连接后，“视频待看”支持点选网页视频、收藏当前页以及粘贴可持久来源，不下载视频。新临时 blob/srcObject 流继续跳过，旧临时收藏和备份保留，其原网页画中画兼容路径仍依附原文档。

点击播放沿用原桌面播放器，不打开播放器网页或承载标签页。B站仍用公开嵌入播放器，不下载、不绕过登录、地区或验证；画质、弹幕和控件由来源决定。实际媒体解码、进度前进后才自动标为已看，打开窗口、iframe load 和加入列表均不算播放成功。

左右箭头打开附属控制区，列表默认展开；置顶、移动、下一条、关闭和安静观看保留。鼠标首次进入后，移出视频和控制区即隐藏并暂停，移回原视频区域恢复此次自动暂停；手动暂停不被覆盖。拖动/调整大小期间保护，隐藏后不挡下层点击。位置写 data/window-position.json。

## 目录与移除

资料库/library.json 是唯一保存库；data 保存自己的缓存和位置；导出文件保存 JSON 备份。它们都在软件文件夹内，不访问已有 Chrome / Edge 资料或 Excel 工作簿。

移动前关闭浏览器、主面板和视频，确保没有软件进程占用文件；不要同时运行新旧目录的两份软件。移动整个软件文件夹，包括资料库、data、导出文件、浏览器插件和运行依赖。新位置运行“摸鱼助手.exe”，软件重新准备连接入口；浏览器加载新位置插件并配对后，确认资料完整再移除指向旧位置的插件项，继续使用原资料库，规则和完整待看不需要重新创建。

移除时建议先导出备份，在软件“设置”点“清除注册表记录”，再关闭浏览器、主面板和视频，移除浏览器插件安装项，最后删除整个软件文件夹。解除操作不删除资料库；直接删除文件夹会连其中的资料和备份一起删除，不能靠重新配对恢复。软件不会在删除文件夹时自动清理登记，也不设置后台删除监控。清理成功后，普通重开不会自动恢复登记；需要连接时再次点击配对。

旧 MSI 安装版继续从 Windows“设置 → 应用”卸载，不要直接搬动或删除安装目录。当前免安装版不替你执行旧安装版卸载。

未连接时默认设置页，另外两个标签禁用；点击“安装浏览器插件”打开浏览器及插件目录，必要时手动输入 chrome://extensions/。EXE 点配对进入等待，再在插件网页确认，实际连接及同步成功后两边绿灯；点亮绿灯不代表视频已经播放成功。

将插件固定到浏览器工具栏，便于查看红点和绿点。绿点表示通信和资料同步已确认，并不表示所有网站已授权；拒绝网站权限时仍会提示相应限制。关闭主面板后若浏览器的轻量通信仍连接，绿点会保留。

## 播放时切换窗口

播放器顶部依次为“安静观看、移动、下一条、关闭视频”，侧栏删除重复的关闭与下一条。播放时隐藏主面板并保留运行状态，关闭视频后恢复同一个窗口，不再重新准备；移出隐藏只作用于视频，不恢复主面板。显式关闭主面板后不自动重开。主界面显示后后台预热无媒体播放器外壳；软件关闭后闲置预热进程退出。真正退出再开仍需初始化，视频网络加载由来源决定。
